# Vinayaga Buildings

Responsive one-page website implemented from the approved Figma design.

## Run locally

Open `index.html` directly, or run a local static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

The repository is ready for GitHub Pages or Cloudflare Pages. No build command is required; the output directory is the repository root.
